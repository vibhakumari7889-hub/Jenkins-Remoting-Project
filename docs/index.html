Jenkins Remoting Project

A small Java project that demonstrates TCP socket communication between a client and a server. It also uses Maven and Jenkins to build and test the application.

View Source Code

About the Project

The client sends a text message to the server using a TCP connection. The server reads the message and sends a response back. The project also includes unit tests for message encoding and decoding.

Message Client

Connects to the server and sends a text message through a socket.

Message Server

Listens for client connections and returns a response after receiving a message.

Message Protocol

Converts messages to and from UTF-8 byte data.

Project Architecture

MessageClient → TCP Socket → MessageServer

MessageServer → Response → MessageClient

The client and server communicate using TCP sockets on port 5000 in the current local implementation.
